ADAM OS 1.0 "First Build"
=========================

Was ist Adam OS?
----------------
Mein eigenes Linux auf Linux Mint 22 Basis.
Kein Bloat, nur das was ich brauche.
Cinnamon Desktop + eigenes Design.

Features
--------
✓ Basis: Linux Mint 22 Cinnamon
✓ Desktop: Eigenes Adam OS Wallpaper  
✓ Boot: Custom Logo beim Starten
✓ GRUB: Angepasster Bootloader
✓ Branding: Überall "Adam OS 1.0"
✓ Kein Snap-Zwang

Systemanforderungen
-------------------
CPU: 1 GHz Dual-Core
RAM: 2 GB min, 4 GB besser
Speicher: 20 GB frei
USB-Stick für Installation

Installation
------------
1. ISO: Adam-OS-1.0-Mint.iso
2. USB-Stick mit Rufus/Etcher erstellen
3. Von USB booten → Install Adam OS
4. Durchklicken → Neustart → Fertig

Unterschied zu Mint
-------------------
• Komplettes Adam OS Branding
• Custom Boot + GRUB Design  
• Vorkonfigurierter Desktop
• Persönliche Version
