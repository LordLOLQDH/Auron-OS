# Contributing to Auron OS

Erstmal: Danke dass du helfen willst ❤️ Ohne Contributors stirbt jedes Open Source Projekt.

> ⚠️ **Status Pre-Release:** Code kommt Freitag 08.05.2026. 
> 
> Bis dahin sammeln wir Ideen + Feedback. PRs für Code erst ab Freitag möglich.

## Wie du JETZT schon helfen kannst

**1. Feature-Wünsche & Diskussion**  
→ [Roadmap Discussion](https://github.com/LordLOLQDH/Auron-OS/discussions) 

Kommentier was Auron OS können muss. Die Top-Votes bau ich ein.

**2. Doku verbessern**  
README typos? Besseres Wording? PRs für `README.md`, `CONTRIBUTING.md` und `LICENSE` nehme ich sofort an.

**3. Design-Ideen**  
Wie soll die GUI aussehen? Mockups, Skizzen, Paint-Screenshots - alles hilft.

## Ablauf ab Freitag wenn Code live ist

1. **Fork** das Repo über den Button oben rechts
2. **Branch erstellen**: `git checkout -b feature/add-fedora-support`
3. **Ändern**: Code anpassen + testen
4. **Commit**: `git commit -m "feat: add Fedora 40 support"` 
5. **Push**: `git push origin feature/add-fedora-support`
6. **Pull Request aufmachen**: Beschreib kurz was du geändert hast

**Ich reviewe jeden PR in 24h.** Versprochen. Auch um 3 Uhr nachts.

## Code Style ab Freitag

- **Python**: Formatier mit `black` wenn du's hast. Wenn nicht, auch egal. Ich fix das.
- **Commit Messages**: `fix:` für Bugfixes, `feat:` für neue Features, `docs:` für README
- **Keep it simple**: Wenn meine Oma den Code nicht versteht, ist er zu komplex

## Was brauchen wir nach dem Launch?

1. **Mehr Distros**: Arch, Fedora, Debian Support
2. **Paket-Listen**: Welche Pakete wollen User standardmäßig?
3. **Bug Reports**: Stürzt was ab? Mach ein Issue mit Log auf
4. **Doku**: README verbessern, GIFs erstellen, Tutorials schreiben

## Fragen?

Diskutier in [Discussions](https://github.com/LordLOLQDH/Auron-OS/discussions) oder mach ein [Issue](https://github.com/LordLOLQDH/Auron-OS/issues) auf und tagg mich mit `@LordLOLQDH`. 

**Noch nie contributed?** Perfekt. Ab Freitag ist dieses Projekt dein Einstieg. Alle haben mal angefangen.
