# Contributing to Auron OS

Danke dass du helfen willst ❤️ 

> ⚠️ **Status Pre-Release:** Erste ISO kommt Freitag 08.05.2026. 
> 
> Bis dahin brauchen wir Feedback + Tester. Code-PRs erst nach Release.

## Wie du JETZT schon helfen kannst

**1. Feature-Voting**  
→ [Roadmap Discussion](https://github.com/LordLOLQDH/Auron-OS/discussions) 

Welche Software MUSS in die ISO? Welche Tweaks willst du? Top-Votes bau ich ein.

**2. Logo/Branding Ideen**  
Wallpaper, Logo, Boot-Screen. Schick Mockups in die Discussions.

**3. Doku**  
README verbessern, Install-Guide schreiben. PRs für `.md` Dateien nehme ich sofort an.

**4. Beta-Tester werden**  
Kommentier in Discussions: "Will testen". Du bekommst die ISO 2 Tage vor allen anderen.

## Nach Release - So hilfst du dann

1. **Bugs melden:** ISO bootet nicht? [Issue aufmachen](https://github.com/LordLOLQDH/Auron-OS/issues) mit Hardware-Details
2. **Paket-Wünsche:** "Bitte nehmt X auf" → Issue mit `package-request` Label  
3. **Build-Skripte:** Wenn du weißt wie man ISOs remastert → PRs willkommen
4. **Doku/Tutorials:** Install-Videos, Wiki-Artikel

## Fragen?

Diskutier in [Discussions](https://github.com/LordLOLQDH/Auron-OS/discussions). Ich antworte in 24h.

**Noch nie bei einer Distro mitgemacht?** Perfekt. Ab Freitag testen wir zusammen.
