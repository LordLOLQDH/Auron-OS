# Contributing to Auron OS

Erstmal: Danke dass du helfen willst ❤️ Ohne Contributors stirbt jedes Open Source Projekt.

## Dein erster PR in 5min

Ich hab extra leichte Issues markiert damit du ohne Stress starten kannst:

**→ [Hier sind alle `good first issue`](https://github.com/LordLOLQDH/Auron-OS/labels/good%20first%20issue)**

Such dir eins raus. Die schaffen wirklich alle.

## Ablauf

1. **Fork** das Repo über den Button oben rechts
2. **Branch erstellen**: `git checkout -b fix/readme-typo` oder `feature/add-spotify`
3. **Ändern**: Code anpassen. Testen mit `python3 main.py`
4. **Commit**: `git commit -m "fix: typo in README"` 
5. **Push**: `git push origin fix/readme-typo`
6. **Pull Request aufmachen**: Beschreib kurz was du geändert hast

**Ich reviewe jeden PR in 24h.** Versprochen. Auch um 3 Uhr nachts.

## Code Style

- **Python**: Formatier mit `black` wenn du's hast. Wenn nicht, auch egal. Ich fix das.
- **Commit Messages**: `fix:` für Bugfixes, `feat:` für neue Features, `docs:` für README
- **Keep it simple**: Wenn meine Oma den Code nicht versteht, ist er zu komplex

## Was brauchen wir gerade?

1. **Mehr Distros**: Arch, Fedora, Debian Support
2. **Paket-Listen**: Welche Pakete wollen User standardmäßig?
3. **Bug Reports**: Stürzt was ab? Mach ein Issue mit Log auf
4. **Doku**: README verbessern, GIFs erstellen, Tutorials schreiben
